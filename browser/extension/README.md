# Nola browser captions

Build from the repository root with `node browser/extension/build.mjs`. Load `browser/extension/dist` as an unpacked extension in Chrome or Edge. The manifest key preserves the extension ID registered by Nola. Keep Nola open and enable its browser connection in Settings.

YouTube and Bilibili are enabled by default. On another HTTPS website, press **Enable on this website** in the extension popup. Permission is limited to that origin and remains enabled after reload. Frames, closed shadow trees, and picture-in-picture are excluded.

Press **Nola captions** in a video player, and press Start. Which audio is captured is decided in Nola: **Share this tab audio** captures the page in the tab, while **Enable captions** on a system source lets the desktop capture the selected output device. Chrome only exposes `getDisplayMedia` inside a real page gesture, so the tab path cannot be replaced by a message from the desktop app and needs the picker; the system path needs neither a gesture nor a picker, and the extension then sends no audio at all. For the tab path, the browser sharing picker opens directly from the press; select the current tab and share its audio. A Capture Handle, origin, display-surface check, and audio-track check reject other tabs, windows, monitors, or unavailable verification. Video tracks are used only to validate sharing; no frames are read or saved.

Caption configuration lives in Nola. The panel offers only Start, Refresh and Close, plus Capture audio for a tab source. Start can open the sharing picker directly or reuse audio prepared by Capture audio. Close stops recognition, releases sharing and hides the panel. Refresh reconnects and reanchors a running session. The largest playing video is selected automatically. Captions stay in memory as the latest phrase. Native-video fullscreen uses a temporary TextTrack; ordinary and container fullscreen use a shadow overlay.

Tab audio is captured without microphone echo cancellation, noise suppression or automatic gain control. Silence displays a recoverable warning rather than ending the session. The extension version is independent of the desktop app: see `../version.json` and `../CHANGELOG.md`. Every hello reports the content bundle's compiled release version, which also generates the manifest; the desktop rejects incompatible starts and offers an installation/reinstallation toast. Reload existing video pages after updating an unpacked extension.

For manual validation, serve `fixtures/player.html` over HTTPS and enable the site. Check selection between two players, wrong-tab/no-audio rejection, picker cancellation/retry, pause/resume, seeking, rate changes, DOM replacement, container and native-video fullscreen, sharing stop, page navigation, desktop shutdown, browser connection disable, and simultaneous desktop/browser session rejection. The fixture generates a tone, so real recognition should be tested separately with spoken audio. Test restrictive CSP sites as well: worklet loading first uses the extension resource URL, then tries an extension-fetched blob; both remain subject to browser security policies. Unsupported loading fails closed and releases the capture stream.

The build emits standalone IIFE content, MAIN capture-handle, worker, and audio worklet scripts, plus a bundled popup; content scripts have no runtime ESM imports.

## Firefox

`npm run build:browser` also writes `dist-firefox/`. In Firefox 128 or newer, open `about:debugging#/runtime/this-firefox`, choose Load Temporary Add-on and select that manifest.json. Temporary installations expire when Firefox closes; permanent release installations require Mozilla signing. `npm run package:browser` creates a separate Firefox ZIP for signing.

Enable/repair the desktop browser connection to register the Mozilla native host. In desktop browser caption settings choose a system output device, then start captions from the video player. Firefox does not implement the Capture Handle verification required by our tab sharing path, so tab audio capture is rejected before opening a picker. System output capture can include other applications playing through that device. Installation state is confirmed when the extension connects; management opens `about:addons`.
