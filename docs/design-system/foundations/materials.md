# 材质

材质帮助区分内容与控件，并传达界面的层次。选择表面时，应同时考虑它承载的信息、下方内容和文字的可读性。

## 浮层材质

浮层位于内容之上，承载临时操作与补充信息。表面、边框和阴影共同说明它与下方内容的关系。

**让浮动控件与内容保持清楚的关系。** 工具跟随它所作用的内容，菜单从对应入口展开。浮层使用独立表面、边框和阴影，让下方内容仍容易辨认。

**根据内容选择透明程度。** 常规浮层使用不透明表面。字幕覆盖视频时可使用半透明衬底，保证背景明暗变化时文字仍然清楚。

字幕衬底服务于文字阅读，菜单表面承载操作。两者分别使用适合内容的表面。

**谨慎使用彩色材质。** 强调色用于当前的重要操作或选择。大面积表面保持中性，使图片与视频保留自身色彩。

## 标准材质

**使用一致的表面层次。** 工作区使用背景色，内容面板使用卡片色，菜单和弹窗使用浮层色。深色模式按同样的关系调整表面明度。

**让文字和控件使用对应前景色。** 浮层中的正文、辅助文字和边界随表面一起变化。使用模糊和透明效果前，应检查其上所有信息的可读性。

**响应用户的辅助功能偏好。** 降低透明度或提高对比度时，提供稳定的实色表面。减少动态效果时，表面切换直接显示最终状态。
