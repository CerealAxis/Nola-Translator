# 布局

布局组织内容和操作，帮助人们理解界面、找到目标，并适应窗口与文字大小的变化。

## 视觉层次

**让重要内容先被看到。** 通过位置、大小和留白确定阅读顺序。标题引出内容，操作靠近对应对象，相关字段组成一组。

**保持清楚的对齐关系。** 标题与正文共享起始边，字段采用稳定的标签与控件关系。可比较的数值在末端对齐，方便纵向阅读。

**逐步呈现次要信息。** 常用操作保持可见，详细设置可按需展开。内容区域保留足够空间，导航和工具维持适当的视觉分量。

## 适配性

**根据实际可用空间调整布局。** 窗口缩放、侧栏展开和文字放大都会改变内容宽度。以内容容器的宽度决定排列方式。

**在布局变化时保留任务关系。** 成组移动标签与控件，保持原文和译文的对应。工具区可收进面板，主要内容继续可读。

## 尺寸分类

**根据宽度和高度分别调整内容。** 较宽窗口可以并排呈现相关内容，较窄窗口按阅读顺序上下排列。高度不足时让内容滚动，标题与必要操作仍可到达。

同一内容在宽窗口中左右对照，在窄窗口中上下排列。窗口标题和内容顺序保持一致。

双语区域不足 45rem 时改为上下排列；设置区域不足 40rem 时，标签置于控件上方。双列表单为每个字段保留至少 15rem，再加组间距。具体尺寸见 DESIGN.md。

## 指南和安全区

**为系统界面与浮动内容留出空间。** 尊重窗口标题栏、拖动区域及系统按钮的位置。内容与控件避免侵入这些区域。

**保持一致的内容边距。** 常规页面使用 24 px 内边距，窄页面使用 16 px。浮层距视口边缘至少 16 px，弹窗高度最多为 80dvh，过长内容在内部滚动。

**让键盘焦点和操作始终可见。** 滚动到字段时同时露出标签和错误信息。放大文字后仍能到达关闭、确认与取消等必要操作。
