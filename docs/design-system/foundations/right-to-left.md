# 从右到左

从右到左的语言需要相应的界面排列。导航、控件和短文本沿界面的阅读方向组织，长段落按自身语言阅读。

## 文本对齐

**让文本对齐方式随界面方向调整。** 标题、标签和短提示沿界面的起始边对齐。LTR 界面的起始边在左侧，RTL 界面在右侧。

**按段落语言对齐长文本。** 英文段落在 RTL 界面中仍从左侧开始，阿拉伯文段落在中文界面中仍从右侧开始。原文与译文分别设置语言和方向，保留各自的阅读顺序。

**让列表条目共享同一条对齐线。** 在 RTL 列表中，拉丁字母和阿拉伯文字的短名称都沿右侧对齐，便于逐项扫读。

布局使用 `text-align: start`、`margin-inline` 和 `padding-inline` 等逻辑属性。已知语言的内容明确设置 `lang` 和 `dir`，来源不定的用户文本可用 `dir="auto"` 判断段落方向。

## 数字和字符

**按区域设置显示数字。** 阿拉伯语地区可能采用不同的数字字形。日期、货币、计量单位与数字格式由用户的区域设置决定。

**保持数字内部的位序。** 数值 `284`、电话号码、版本号和时间在 RTL 界面中仍保持原有顺序。路径、网址、电子邮箱和标识符使用 `<bdi>` 隔离，方向明确的完整路径与代码使用 `dir="ltr"`。复制后保留原始字符次序。

**让表示进度的数字序列随控件调整。** 滑块端点、评分和步骤从 RTL 界面的右侧开始排列。序列的起点改变，每个数字内部的位序保持原样。

混排时检查括号、标点、正负号和斜线的位置。文件名或网址包含方向控制字符时，提供可检查的原始值或转义显示。

## 控制

**调整表示数值增长的控件。** RTL 滑块从右侧开始填充，最小值和最大值的标签随端点移动。由 Base UI 的方向上下文统一管理轨道、滑块和方向键行为。

**调整按顺序导航的控件。** 返回、上一步和下一步随阅读顺序改变位置与箭头方向。RTL 界面的返回箭头指向右侧。

**保留表示实际方向的控件含义。** 「向右移动」仍使对象向右移动。地图方位、画布坐标和原始波形遵循自身坐标。媒体播放保留用户熟悉的时间轴和播放符号。

**平衡不同文字的视觉大小。** 检查阿拉伯文、希伯来文与拉丁字母相邻时的字面大小、基线和上下裁切。采用适合语言的字体与行高，让按钮能随标签增长。

DOM 保持符合阅读顺序，Tab 顺序跟随内容，方向键遵循控件语义。输入光标、选区及 Home/End 使用浏览器与输入法的默认行为。

## 图像

**保持图像内容的原貌。** 照片、漫画、截图、标志与一般插图的镜像可能改变内容含义。图像依赖阅读方向时，另行制作本地化版本。

**调整有顺序的图像排列。** 一组图像表达步骤、时间或收藏顺序时，从界面的起始边排列，保留每张图片的内容和编号。漫画按作品自身的阅读方向翻页。

## 界面图标

**调整表达文本方向的图标。** 起始对齐、段落和列表图标中的文本条随 RTL 改为右对齐。包含字母的字体、签名或语言工具选择适合书写系统的本地化版本。

**调整表达前后动作的图标。** 返回、前进以及表达向前传播的图形，使用对应的方向版本。

**保留标志和通用符号。** 品牌、勾选、搜索和时钟保持熟悉的形态。描述真实工具的图标按工具本身呈现，避免因阅读方向改变惯用手的含义。

**分别处理复合图标的组成部分。** 主体、角标、禁止斜线和放大镜可能遵循不同规则。选择方向变体后，检查各部分的含义和整体视觉平衡。
