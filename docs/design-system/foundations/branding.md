# 品牌

产品名称、标志、用语和控件共同形成品牌识别，让用户在不同窗口中认出熟悉的内容与操作。

## 最佳实践

**在各处使用一致的语气。** 界面直接说明动作与结果。按钮写“导出译文”，等待时写“正在识别语音”，失败时说明如何重试。首页、设置和错误提示使用同一套名称。

**有选择地使用强调色。** 把蓝色用于主要操作、当前选择或需要注意的状态。筛选和导出同时出现时，可以让两者保持中性，把强调色留给正在查看的条目。

两侧展示同一份术语库。蓝色从工具按钮移到选中项后，用户更容易看清当前正在查看的内容。勾选标记也保留了选择状态。

**选用适合阅读的字体。** 界面使用系统字体。品牌字形用于标志等身份标识。若为标题引入专用字体，检查不同字号、字重和语言下的可读性，并保留文字放大能力。具体文本样式见[字体排印](./typography)。

**保留熟悉的组件和操作。** 保存、取消、返回等动作沿用常用控件和位置。用户应能凭标签和外观找到操作，并用熟悉的键盘方式完成。

**让内容占据主要空间。** 把阅读区域留给原文和译文，把工具条留给任务所需的操作。标志和名称适合放在窗口标题区、关于页或首次使用界面。标志与产品名称并列时，使用空替代文本避免重复朗读。

**让启动尽快交接给内容。** 恢复上次任务或显示可操作的首页。首次使用时，可在欢迎页简短介绍产品和下一步。

**保持品牌资源的识别性。** 使用既有标志和完整产品名称。第三方服务标志保持原有比例和含义，与服务名称一起出现。界面强调色随主题切换，品牌图形保留其颜色。
