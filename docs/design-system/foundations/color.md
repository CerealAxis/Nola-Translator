# 颜色

颜色能够突出重要信息、帮助识别操作，并传达状态。以中性色组织界面，让蓝色承担操作和选择的含义。

## 最佳实践

**在相同的情境中保持颜色的含义一致。** 链接、主要操作和选中项分别使用对应的语义颜色。同一种状态在不同页面中保持一致。

**在实际使用环境中选择颜色。** 同一颜色在浅色、深色和不同背景上的表现会有变化。分别为两种外观提供配色，保留同样的信息层次。

同一列表在两种外观中保留选中底色、勾选标记和文字。背景与文字成对调整。

**考虑周围内容对颜色的影响。** 图片、视频和其他彩色内容会改变相邻颜色的观感。需要稳定辨认的文字和控件使用独立表面，避免直接叠在复杂背景上。

## 包容性颜色

**用颜色和其他线索共同表达信息。** 状态同时提供图标与名称，选中项保留勾选标记。用户即使无法分辨颜色，也能识别结果。

**考虑颜色在不同文化中的含义。** 红色和绿色在不同地区可能代表相反的趋势。数据变化应标明增减方向和数值，成功与失败应有明确文字。

普通文字与背景的对比度至少为 4.5∶1。必要的控件边界、选中标记和焦点至少为 3∶1。辅助文字也需要在实际表面上清晰可读。

## 系统颜色

**按用途选择语义颜色。** 正文、辅助文字、面板、浮层和选中项各有对应角色。浅色与深色切换时一起替换配对值，组件沿用原有角色。

主要操作使用 `primary` 与 `primary-foreground`，选中内容使用 `selection` 与 `selection-foreground`。焦点使用独立外框，让已选中的控件仍能显示键盘焦点。具体值见 DESIGN.md。

## 表面颜色

菜单、工具栏和弹窗使用中性表面，通过边框和明度差呈现层级。浮层中的文字、图标与背景成对选择，保持清晰的对比。

**让颜色突出当前任务的重要操作。** 同一区域的主要操作使用蓝色填充，辅助操作使用中性填充或描边。图像和模型标志保留自身颜色，避免与操作色混淆。

## 颜色管理

**让同一图像在不同显示环境中保持一致。** 界面颜色按 sRGB 定义。导入与导出图像时保留色彩配置文件，预览沿用浏览器的颜色管理。评估截图和图片颜色时，使用原始素材及其配置文件。
