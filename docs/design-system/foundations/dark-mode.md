# 深色模式

深色模式以较暗的表面呈现界面，在保留内容层次的同时减少明亮背景。浅色与深色应提供同样完整的阅读和操作体验。

## 最佳实践

**尊重用户选择的外观。** 默认跟随系统，并允许用户在设置中选择浅色或深色。系统外观变化时及时更新当前界面。

**保持两种外观中的信息和操作一致。** 切换后保留页面结构、选择和输入内容。媒体本身保留原有色彩，围绕媒体的控件随界面外观调整。

**结合辅助功能检查深色外观。** 在增大文字、提高对比度和不同显示亮度下，正文、边界与状态仍应容易辨认。

## 深色模式颜色

**使用随外观变化的语义颜色。** 深色模式通过工作区、面板和浮层的明度差表达层次。正文和辅助文字分别使用对应前景色，分隔线使用边界色。

两种外观保留相同的表面层级和文字关系。浮层通过独立表面与边框从内容中浮起。

**根据背景调整强调色。** 浅色主操作使用深蓝底白字，深色改用浅蓝底深字。状态色也随外观变化，保证在中性表面上的辨识度。

## 图标和图像

**让界面图标适应背景。** Lucide 图标继承文字或对应状态颜色。模型标志保留原始比例和颜色，需要时选用品牌提供的深色版本。

**检查图像的透明区域和边缘。** 深色描边可能在深色背景中消失，白色底块也可能格外突出。为需要衬底的素材提供合适的中性表面。照片、视频和用户图片保持原貌。

## 文本

**让文字与表面一起调整。** 正文使用高对比度前景色，时间和附加信息使用辅助文字色。提高文字明度时，避免同时提高所有分隔线和边框的明度。

**使用字重和层级增强可读性。** 标题、正文和辅助信息沿用完整文本样式。深色外观中的文字保持足够字重，长段内容保留行距和阅读宽度。
