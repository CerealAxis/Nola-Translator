# 图标

图标用精简的图形表达一个概念，帮助用户认出操作、对象与状态。界面中的图标应与相邻文字、控件和其他图标保持协调。

## 最佳实践

**选择容易识别的图形。** 使用用户熟悉的视觉含义，把细节控制在表达概念所需的范围内。常规操作采用 Lucide 线性图标，保持相同动作的图形一致。

**保持视觉一致性。** 比较图标的大小、细节、线条粗细和视重。常规操作图形为 16px，较大的导航或空状态可用 20px。图形大小与操作区域分别处理，16px 图形放在至少 36 × 36px 的图标按钮中。

**让图标与文字相称。** 图标的视觉重量接近相邻文字，图形与标签垂直对齐。使用库中已有组件时，由组件管理图标尺寸与间距。自绘的非对称图标还需检查视觉中心，在资源内部保留适当内边距。

**由控件表达选中状态。** 按钮、标签页和导航项通过填充、选中指示和文字色显示状态。仅当图形本身的含义变化时，才使用相应变体，例如麦克风开启与关闭。

**使用能被不同用户理解的图形。** 人物符号采用中性的形象，文化含义不明确的手势配上文字。图标包含单个字符时，选择适合书写系统的版本；表示段落时使用抽象线条，并检查 RTL 方向。

**保留清晰的资源与名称。** SVG 适合平面界面图标。为独立图标操作提供准确的可访问名称，装饰图标从辅助技术中隐藏。必要的动作名称保持可见，补充 tooltip 同时支持悬停和键盘焦点。

## 标准图标

图形沿用常见含义，操作名称说明它将作用于什么。以下为本项目组件库中的对应选择。

### 编辑

| 操作 | 图标 | 用法 |
| --- | --- | --- |
| 剪切、复制、粘贴 | `Scissors`、`Copy`、`ClipboardPaste` | 针对当前内容或选区 |
| 保存、关闭 | `Save`、`X` | 用文字区分保存、取消与关闭 |
| 删除 | `Trash2` | 标明受影响的对象 |
| 撤销、重做 | `Undo2`、`Redo2` | 保留熟悉的前后操作含义 |
| 新建、更多操作 | `Plus`、`Ellipsis` | 与当前位置及对象保持关联 |

### 选择

选择状态使用 Checkbox、RadioGroup 或选中指示。全选、清除选择和删除是不同动作，提供明确名称，并保留部分选中的状态。

### 文本格式化

加粗、斜体和下划线使用 `Bold`、`Italic`、`Underline`。段落对齐使用 `AlignLeft`、`AlignCenter`、`AlignRight` 和 `AlignJustify`，按实际语义检查阅读方向，保留用户对当前格式的判断。

### 搜索

`Search` 表达查找内容，`ListFilter` 表达缩小已有结果范围。两者出现于同一区域时，标签分别说明搜索对象和筛选条件。

### 共享和导出

共享、下载和打印采用不同图形。`Share2` 用于共享入口，`ArrowDownToLine` 用于导出或下载，`Printer` 用于打印。操作名称同时说明结果和对象。

### 用户和账户

账户使用 `UserRound` 等中性人物图形。模型、服务商的身份使用 LobeHub Icons 的对应品牌资源，并在旁边显示完整名称。

品牌图形保留原始比例。已有单色版本可以跟随文字色；彩色资源保留品牌配色，并在浅深色背景中检查。

### 评分

点赞、反对和收藏分别使用 `ThumbsUp`、`ThumbsDown`、`Star` 等图形。使用选中状态表达用户已经执行的动作，并让计数与状态保持一致。

### 层叠顺序

对象前移、后移和置于顶层或底层使用对应的层叠图形。名称明确写出移动的方向与范围，帮助用户区分调整一层和移动到边界。

### 其他

提醒、归档和日历使用 `AlarmClock`、`Archive`、`Calendar` 等熟悉图形。界面中的同一图形保持相同含义，涉及阅读方向的图标与所在控件一起调整。
