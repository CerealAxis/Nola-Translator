# 图像

图像在不同显示密度、尺寸与外观中都应保持清晰。制作资源时，同时考虑显示尺寸、像素数量、格式和颜色，让用户在实际使用环境中看到完整且准确的内容。

## 分辨率

界面中的显示尺寸与位图的像素数量分别决定图像的大小和细节。相同的显示区域，在 2 倍或 3 倍显示密度下需要更多像素，才能保持边缘清晰。

为位图提供与实际显示密度相匹配的资源。例如，24 个 CSS 像素的图像，在 2 倍显示密度下需要 48 个物理像素。检查缩略图、窗口缩放和高密度屏幕，避免将小位图直接放大。

平面形状优先保留矢量源文件，关键轮廓在最低目标分辨率下也要清晰。导出位图时，检查边缘与像素网格的关系，并为不同输出保留相同构图。

## 格式

按照图像内容和目标环境选择格式。

| 图像内容 | 资源选择 |
| --- | --- |
| 平面图标、标志和可缩放插图 | SVG；原生交付可采用相应矢量格式 |
| 带透明度的位图插图 | PNG，保留透明边缘与细节 |
| 颜色较少的平面位图 | 调色板 PNG，检查色阶与透明度 |
| 照片与复杂画面 | JPEG；按宿主平台的支持情况使用 HEIC 等格式 |
| 漫画、截图和文字密集图片 | 优先保留原始资源，压缩后检查文字和细线 |

选择格式时同时检查文件体积、解码支持和画质。透明图像在浅深色背景中检查边缘，照片与截图保持原有内容和方向。

## 最佳实践

**保留正确的颜色描述。** 图像的颜色信息帮助不同显示器呈现一致的内容。导出、转换和压缩后，检查颜色描述是否保留，尤其关注渐变、肤色和大面积纯色。

**在实际显示环境中检查。** 设计工具中的预览完成后，还要检查不同显示密度、缩放比例、窗口尺寸和浅深色外观。查看边缘是否像素化，图像是否被拉伸，重要细节是否仍然可读。

为图片预留合适的尺寸与比例，让资源到达后保持周围布局稳定。完整阅读内容与缩略图使用各自需要的资源尺寸，保留查看完整图像的入口。
