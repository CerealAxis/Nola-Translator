# 设计原则

设计原则用于判断信息怎么排、操作放在哪里，以及页面变化后用户能否看清结果。本章沿着这三个问题阅读。

[亲密性](./structure)、[对齐](./alignment)、[对比](./contrast)、[重复](./repetition)组织信息。[直截了当](./interaction)、[足不出户](./stay)、[简化交互](./lightweight)、[提供邀请](./invitation)安排操作。[巧用过渡](./transition)和[即时反应](./response)说明变化与反馈。

具体颜色、字号和间距见 [DESIGN.md](/vis/DESIGN)。
