# 状态与反馈文案

反馈告诉用户任务到了哪一步，以及接下来可以做什么。把结果放在相关内容附近，用简短、准确的文字说明当前状态。

## 等待与进行中

说明正在执行的动作。短操作可在按钮上显示「正在保存」，较长的任务应显示当前阶段，例如「正在校验文件」。知道处理总量时，再补充数量或进度。

| 情境 | 文案示例 |
| --- | --- |
| 等待执行 | 等待下载 |
| 正在处理 | 正在识别第 3 页，共 12 页 |
| 等待响应 | 正在连接翻译服务 |

阶段变化时同步更新文字。百分比和剩余时间应来自实际进度。用户可以中止任务时，将「取消下载」或「停止识别」放在进度附近。

## 成功与完成

指出完成的动作和对象，例如「已保存字幕样式」「已导出 8 条记录」。数量、文件名或保存位置能帮助用户确认结果时再加入。

简单完成反馈使用简短提示。导出的文件、处理后的记录和更新后的设置在页面中保留可见结果。可撤销的移除操作可以附「撤销」，需要后续处理时提供「打开文件夹」等具体入口。

## 表单校验

在对应字段旁说明填写条件和修改方法，例如「请输入方案名称」「名称最多 30 个字符」。格式提示可以先出现，错误信息在用户需要修正时出现。

保留已填内容，让用户直接修改出错的部分。多个字段出错时，分别显示各自的问题，提交后将焦点移到第一个无效字段。统一的「请检查表单」可以作为汇总，具体原因仍跟随字段。

## 失败与恢复

先说明哪个动作未完成，再给出当前可执行的处理方法。已知原因写具体，例如「网络连接已断开」。原因尚未确认时，写明可观察到的结果，例如「翻译服务未响应」。

恢复入口与问题对应。连接中断提供「重试」，文件夹不可写提供「选择其他位置」。错误编号、请求 ID 等诊断信息放在详情中，并允许复制。

点击「显示错误通知」查看下载中断的提示。示例中的「重试下载」展示操作入口，选择后收起通知。

提示中的「已保存」「已保留」应与实际数据状态一致。部分完成时说明范围，例如「已导出 6 条记录，另有 2 条未完成」，并提供处理剩余内容的入口。

## 空状态

区分尚未添加内容、搜索无结果和加载失败。它们有不同的原因，也需要不同的下一步。

| 情境 | 文案示例 | 操作 |
| --- | --- | --- |
| 首次使用 | 暂无术语 | 添加术语 |
| 搜索无结果 | 没有匹配的术语 | 清除筛选 |
| 加载失败 | 无法加载术语库 | 重试 |

空状态标题说明当前事实，必要说明帮助用户开始或恢复任务。列表已有清楚的标题时，状态文字无需重复介绍整项功能。

## 权限与帮助

请求权限时说明访问对象和用途，例如「使用麦克风采集你的声音，生成实时字幕」。涉及云端处理时，说明会发送的内容及接收服务。

权限被拒绝后，说明受影响的操作，并提供「打开系统设置」或「选择其他音源」等可用入口。帮助链接直接命名主题，例如「查看麦克风权限设置」。提示中引用的名称应与实际入口一致。
