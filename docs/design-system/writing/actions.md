# 操作名称

用户应能从名称预判操作结果。按钮写动作，菜单和链接说明将打开的内容，确认操作写清影响的对象。

## 按钮

用动词表达操作，例如「保存」「添加术语」「导出字幕」。对象已在当前区域清楚呈现时，可以省略重复的对象名。离开上下文后容易混淆的操作，保留对象。

| 情境 | 操作名称 |
| --- | --- |
| 提交当前表单 | 保存 |
| 创建一条记录 | 添加记录 |
| 将记录写入文件 | 导出记录 |
| 建立新的连接 | 连接 |
| 再次建立中断的连接 | 重新连接 |

「继续」用于仍有后续步骤的流程，「完成」用于结束当前流程。操作会打开下一步时，先在界面中交代那一步需要选择什么。

## 菜单与链接

进入页面或打开对话框的名称，与目标标题保持一致。例如，入口写「导出字幕」，打开后仍以「导出字幕」为标题，执行按钮写「导出」。名称连续，用户便能确认仍在同一任务中。

链接说明目标内容，例如「查看模型要求」「打开下载文件夹」。链接单独被朗读时，也应能让人判断用途。图标菜单使用明确的动作提示，键盘焦点与指针悬停时均可读取。

## 确认操作

标题提出当前需要决定的事，正文说明对象与后果，按钮命名实际动作。例如，「替换已有文件？」配合文件名和「替换后将覆盖原文件」的说明，操作为「取消」与「替换」。

永久删除、覆盖文件等操作，应在执行前说明影响范围。按钮使用「删除」「替换」等准确名称。可恢复的移除，可以在完成后提供「撤销」，让用户直接恢复该对象。

## 取消、关闭与停止

用词取决于用户离开的是输入过程、信息视图还是正在执行的任务。

| 名称 | 含义 | 使用情境 |
| --- | --- | --- |
| 取消 | 放弃本次尚未提交的选择或修改 | 退出正在填写的表单 |
| 关闭 | 收起当前视图 | 离开预览或详情 |
| 停止 | 结束正在执行的任务 | 结束识别或翻译 |
| 暂停 | 暂时中止，并允许从当前位置继续 | 暂停可继续的处理任务 |

关闭进度视图后，任务若会继续运行，应在视图中说明。停止任务会影响已有结果时，在操作前交代会保留哪些内容。按钮名称与实际行为保持一致。
