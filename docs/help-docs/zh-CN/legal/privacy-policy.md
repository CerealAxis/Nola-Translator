# 隐私政策

更新日期：2026 年 10 月 22 日

本应用重视您的隐私。您使用 Nola Translator 时，软件会按照本《隐私政策》处理信息。本政策说明桌面软件和浏览器字幕扩展如何处理音频、字幕、设置、凭据和诊断信息，以及您如何访问、管理和删除这些信息。

音频、字幕和设置默认保存在本机。您选择云端识别或翻译并开始会话时，软件会将该功能所需的信息发送给您选择的服务商，您的个人隐私由您选择的服务商负责。

如您对本政策或个人信息处理有疑问，可通过本页末尾的项目反馈渠道联系维护者。该渠道为公开页面，请不要在那里提交录音、字幕、API 密钥或其他个人信息。

## 我们处理的信息

### 您提供的信息

您通过软件选择或提供的信息包括音频输入来源、识别和翻译服务、语言、模型、字幕显示设置，以及您输入的 API 密钥和 MyMemory 联系邮箱。

桌面同传会在本机保存您使用软件时产生的会议记录，包括识别文本、译文、语言和时间。软件默认开启录音保存；开启时，录音文件也保存在本机会议记录中。您可以在设置中关闭录音保存，并在软件中删除会议记录。

浏览器字幕以临时会话运行，不创建桌面会议记录或录音文件。浏览器扩展把会话所需的音频发送给本机桌面程序处理。

### 其他人提供或出现在内容中的信息

录音和字幕可能包含其他人的声音、谈话内容或个人信息。软件不会从社交账号、通讯录或其他账户服务获取有关您的信息；软件也没有用户注册、社交分享或账户登录功能。

### 软件生成的信息

软件在本机生成运行和故障诊断日志，其中可能包括软件版本、操作阶段、错误代码和设备运行信息。日志会过滤 API 密钥、字幕文本和录音数据等常见敏感字段，并按最近五次启动保留。设置中的“复制诊断信息”会把报告复制到剪贴板；您之后主动粘贴或发送时，报告才会离开本机。发送前请检查报告内容。

### 网络请求信息

检查更新、下载模型或运行组件，以及连接识别或翻译服务时，相应网站或服务会收到网络请求所需的技术信息，例如 IP 地址、请求时间和客户端网络信息。软件不会收集您的定位信息，也不会记录您在其他网站的搜索和浏览内容。

## 我们如何使用您的信息

软件在本机处理音频和文本，用于语音识别、翻译、字幕显示和会议记录。使用本地模型时，推理在本机完成；下载模型和运行组件时，软件会连接对应的发布站点。

您选择云端识别时，软件会把实时音频和识别所需参数发送给所选识别服务。您选择云端翻译时，软件会把待翻译的识别文本、源语言和目标语言发送给所选翻译服务。本机识别搭配云端翻译时，音频留在本机，但识别文本会发送给翻译服务；云端识别搭配本机翻译时，音频仍会发送给识别服务。

API 密钥用于向对应服务验证请求。您在 MyMemory 设置中填写的联系邮箱会随 MyMemory 翻译请求发送。

您主动检查软件更新时，软件会访问 GitHub Releases API 查询版本信息。软件不会把本机的音频、字幕或会议记录用于用户画像、广告投放、营销或问卷调查。

## 如何访问和控制您的信息

您可以在软件中查看、复制、导出和删除会议记录；在设置中关闭录音保存、更换或清除 API 密钥；也可以通过软件或操作系统文件管理器删除日志、模型和其他本机文件。停止会话会停止本次音频处理；切换到本地模型会停止后续发往相应云端服务的请求。

软件没有用户账户或由维护者托管的转录记录，维护者无法从服务器检索或删除您本机保存的记录。对于已发送给第三方服务的信息，您需要直接向相应服务商提出查阅、更正或删除请求。

## 我们如何分享您的信息

Nola Translator 维护者不接收通过第三方 API 发送的录音、字幕或 API 密钥。选择云端服务后，软件会将相关请求直接发送到您选择或填写的服务端点：

| 服务或功能 | 发送的信息 | 接收方 |
| --- | --- | --- |
| 阿里云云端识别 | 实时音频、模型和识别参数，以及服务所需的 API 密钥 | 阿里云百炼模型服务端点 |
| MiniMax 云端识别 | 分段音频、模型和识别参数，以及服务所需的 API 密钥 | MiniMax 语音识别接口 |
| 云端翻译 | 识别文本、源语言、目标语言，以及服务所需的 API 密钥 | MyMemory、Google、Microsoft、Index-Translate、阿里云原生译文服务或您配置的兼容 API |
| MyMemory 联系邮箱 | 如您在软件中填写邮箱，该邮箱会随翻译请求发送 | MyMemory |
| 模型和运行组件下载 | 下载请求和网络信息 | GitHub、Hugging Face、PyPI、PyTorch 下载站或您配置的镜像 |
| 软件更新检查 | 版本查询请求和网络信息 | GitHub Releases API |

第三方服务按自己的条款和隐私政策处理收到的信息，包括保存期限和跨境传输安排。自定义 API 地址会收到发往该地址的请求。使用前请确认接收方、服务规则和计费方式。Nola Translator 维护者不控制第三方服务如何储存或处理已收到的信息。

我们会在法律要求时，按适用法律、法院命令或主管机关要求提供依法必须提供的信息。

## 我们如何保留、储存和保护您的信息

设置、凭据、日志、模型和会议记录保存在本机。会议记录和录音会保留到您在软件中删除记录或清理对应的本机数据。卸载软件不一定会删除单独保存在用户数据目录中的记录、凭据或模型文件。诊断日志按最近五次启动保留；第三方服务收到的信息按其自身规则保存。

## 有关共享信息的提示

您可以通过软件导出会议记录，也可以在公开反馈页发布文字或诊断信息。您主动发布的内容可能被页面访问者查看、复制或保存；删除本机记录不会删除您已经发布到公开页面的内容。提交诊断报告前，请检查并移除录音、字幕、API 密钥和其他不打算公开的信息。

## 有关敏感个人信息的提示

录音可能包含可识别个人的声音、谈话内容、健康信息或其他敏感信息。软件将音频用于识别和字幕功能，不根据录音建立说话人身份档案。开始录音、处理他人内容或将音频和文本发送到云端服务前，请确认您有权处理这些内容，并已取得所在地法律要求的授权或同意。

请谨慎选择录音来源、云端服务和处理内容。您可以选择本地识别与本地翻译，以避免向云端推理服务发送音频和文本；软件检查更新或下载模型时仍会连接相应站点。

## Cookie、日志档案和网页信标

桌面软件和浏览器字幕扩展不使用广告追踪 Cookie、网页信标或用于分析使用行为的服务。软件的诊断日志保存在本机，不会自动发送给维护者。

本政策不适用于项目文档、GitHub、模型下载站或其他第三方网站。您打开这些网页时，网站运营方会按其隐私政策处理访问请求；项目文档使用页面访问统计和评论功能。

## 与服务有关的公告

软件可能显示您主动检查更新后从 GitHub 获取的版本信息。项目维护和帮助公告由相应的项目页面发布；打开这些页面时，适用该网站自己的隐私政策。

## 本软件中的第三方服务

软件可连接您选择的阿里云百炼、MiniMax、MyMemory、Google、Microsoft、Index-Translate、自定义 API、模型下载站和运行组件下载站。软件也可能打开 GitHub 或帮助文档中的其他网站。您使用这些服务或网站时，您向其提供的信息受其自己的服务条款和隐私政策约束，而非本政策。请在使用前阅读相应规则。

## 年龄限制

本软件不是专为未成年人设计的。未成年人使用软件或向云端服务发送音频和文本前，应由监护人了解相关处理方式，并遵守所在地法律和服务商的年龄及同意要求。

## 本《隐私政策》的适用范围

本政策适用于 Nola Translator 桌面软件和浏览器字幕扩展，不适用于第三方服务或网站。项目文档站和浏览器演示由网站技术提供方按其网站规则处理访问数据。

## 本《隐私政策》的修改

软件处理信息的方式发生变化时，我们会更新本政策并修改更新日期。您可以在项目文档站查看当前版本。若变更需要另行取得您的同意，我们会按适用法律处理。
