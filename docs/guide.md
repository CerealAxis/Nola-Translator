# 快速上手

Nola Translator 将系统音频或麦克风语音实时转写并翻译为双语字幕。以下步骤帮助你在 Windows x64 上完成初始配置。

## 1. 下载安装

从 [GitHub Releases](https://github.com/CerealAxis/Nola-Translator/releases/latest) 下载适用于 Windows x64 的安装包，运行安装程序并启动应用。

## 2. 配置识别与翻译模型

进入「模型管理」，选择适合的语音识别模型和文本翻译模型。两种模型可独立配置：

- **语音识别**：支持 Qwen、Paraformer 等本地模型，以及阿里云 LiveTranslate、MiniMax 等云端服务。
- **文本翻译**：支持 Hy-MT2、Index-Translate 等本地模型，以及 MyMemory 公开 API 等云端服务。

本地模型需要下载模型权重和运行组件，对显存和内存有一定要求。云端服务需要网络连接，部分服务需要配置 API 凭据。

## 3. 设置推理引擎

进入「设置」的「计算」面板：

- **推理引擎**：选择 llama.cpp 或 PyTorch。
- **推理设备**：选择 NVIDIA GPU 或 CPU。GPU 推理需要相应的驱动和显存支持。

## 4. 开始实时翻译

打开「快速同传」：

1. 选择音频来源（系统音频或麦克风）。
2. 设定源语言和目标语言。
3. 选择识别模型和翻译模型。
4. 点击开始。

工作区支持双语、仅原文、仅译文三种显示模式，以及逐句或分区对照布局。完成后可在「记录」中查看字幕和笔记。
