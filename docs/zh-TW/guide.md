# 快速入門

Nola Translator 將系統音訊或麥克風語音即時轉寫並翻譯為雙語字幕。以下步驟協助你在 Windows x64 上完成初始設定。

## 1. 下載安裝

從 [GitHub Releases](https://github.com/CerealAxis/Nola-Translator/releases/latest) 下載適用於 Windows x64 的安裝程式，執行安裝並啟動應用程式。

## 2. 設定辨識與翻譯模型

進入「模型管理」，選擇適合的語音辨識模型和文字翻譯模型。兩種模型可獨立設定：

- **語音辨識**：支援 Qwen、Paraformer 等本機模型，以及阿里雲 LiveTranslate、MiniMax 等雲端服務。
- **文字翻譯**：支援 Hy-MT2、Index-Translate 等本機模型，以及 MyMemory 公開 API 等雲端服務。

本機模型需要下載模型權重和執行元件，對顯示記憶體和記憶體有一定需求。雲端服務需要網路連線，部分服務需要設定 API 憑證。

## 3. 設定推論引擎

進入「設定」的「計算」面板：

- **推論引擎**：選擇 llama.cpp 或 PyTorch。
- **推論裝置**：選擇 NVIDIA GPU 或 CPU。GPU 推論需要相應的驅動程式和顯示記憶體支援。

## 4. 開始即時翻譯

開啟「快速同傳」：

1. 選擇音訊來源（系統音訊或麥克風）。
2. 設定來源語言和目標語言。
3. 選擇辨識模型和翻譯模型。
4. 點選開始。

工作區支援雙語、僅原文、僅譯文三種顯示模式，以及逐句或分區對照版面。完成後可在「記錄」中查看字幕和筆記。
