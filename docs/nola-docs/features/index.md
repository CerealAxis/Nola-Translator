# 功能介绍

Nola Translator 根据字幕显示的位置和记录需求提供不同入口。识别、翻译和模型配置由桌面统一管理；工作区、悬浮窗和浏览器页面负责各自的阅读与控制。

本节说明如何完成真实任务。首次使用还应先完成[开始入门](../getting-started/index)，不能只打开字幕窗口就期待已经有可用模型。

## 一、选择使用入口

| 入口 | 主要用途 | 字幕位置 | 记录特点 |
| --- | --- | --- | --- |
| 快速同传 | 集中阅读、笔记、会后整理 | 主窗口工作区 | 桌面记录，可按配置保存录音 |
| 悬浮字幕 | 配合视频或其他应用阅读 | 独立桌面窗口 | 桌面会话，按相应配置保存 |
| 浏览器字幕 | 在视频播放器内看双语 | Chrome／Edge 页面 | 临时会话，不保存桌面会议 |

桌面和浏览器共用单会话资源。需要换入口时，先结束原会话；最小化、隐藏或关闭某个设置页不等于停止识别。

## 二、快速同传

[快速同传](./live-translation)从音源测试开始，介绍新建窗口、开始前检查、字幕对照、笔记、暂停、结束、回放及 TXT／SRT／WebVTT 导出。

适合需要回顾内容和形成文字记录的任务。保存录音需在开始前确认，关闭后不能事后补回未保留音频。

## 三、悬浮字幕

[悬浮字幕](./floating-captions)说明打开独立窗口、开始收音、拖动、缩放、置顶、锁定、样式与关闭。窗口样式独立于主界面主题和浏览器字幕。

适合边操作其他应用边读字幕。窗口不可见或最小化时仍应检查会话状态，特别是正在使用计费服务时。

## 四、浏览器字幕

[浏览器字幕](./browser-captions)说明扩展安装、站点许可、桌面连接、标签页与系统音源、共享授权、播放跳转及版本更新。

它需要扩展、Native Messaging 和桌面服务共同工作。嵌入播放器、页面权限和浏览器安全限制会影响可用性，不保证所有网站都支持。

## 五、系统设定

[系统设定](./settings)按实际设置页解释网络、识别、翻译、计算设备、性能与显存、两套字幕外观、存储、诊断和恢复。

阅读设置前先确定当前任务是本地还是远程。模型、运行组件、设备及服务凭据解决不同问题，不能互相代替。

## 六、验证与排错

先用两秒回放确认输入，再用短会话确认识别与翻译，最后检查显示和记录。只检查页面截图不足以证明真实推理可用。

故障按[常见问题](../troubleshooting/faq)区分阶段，涉及数据处理和分享范围则查看[隐私协议](../legal/privacy-policy)。
