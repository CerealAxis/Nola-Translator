# 常见问题

>[!TIP]
> AI攥写，待完善

本页按故障阶段提供检查方法。每次只修改一个相关变量，并保留错误提示；反复重装、换模型和重置设置会增加定位成本，也可能覆盖原始线索。

如果是首次配置，先完成[环境配置](../getting-started/environment)和模型设置。无法按下述方法解决时，按[如何反馈](./feedback)提供可复现材料。

## 一、先判断问题在哪一层

| 能确认的现象 | 已验证的部分 | 下一步重点 |
| --- | --- | --- |
| 主窗口可以打开 | Electron 界面启动 | 不代表引擎或模型可用 |
| 两秒测试听到正确声音 | 采集输入基本正确 | 检查模型、组件和语言 |
| 已显示识别原文 | 采集及识别正在工作 | 检查翻译链路 |
| 原文和译文均出现 | 当前短会话链路有效 | 检查稳定性、质量和记录 |
| 演示网页有字幕 | 仅演示页面与内存数据正常 | 仍需验证真实桌面环境 |

这个顺序可以避免把翻译错误当作音频问题，或把云端认证失败当作本地组件缺失。

## 二、音频采集 {#audio}

### 1. 测试完成但没有听到声音

先让目标应用播放持续语音，再重新测试；测试时没有声音，可能只是正确采集了静音。

按顺序检查：

1. “音频来源”是实际输出设备还是麦克风，是否选错类型。
2. Windows 当前输出是否切到耳机、显示器或蓝牙设备。
3. 目标应用是否单独指定了另一输出设备，是否被系统音量混合器静音。
4. 麦克风模式下，设备与桌面应用访问权限是否允许。
5. 默认输出不可用时，明确选择一个可见的输出端点再试。

不要只根据任务管理器电平或“采集完成”判定正确。应能在两秒回放中辨认目标内容。

### 2. 听到的是其他应用或自己的声音

说明采集到信号，但来源不符合任务。系统输出会混合该设备上其他应用的声音；麦克风会收录现场内容。暂停其他播放源，核对输出路由，或在浏览器场景改用受授权的标签页声音。

麦克风可能再次录入扬声器播放声，造成回声或重复内容。软件不为输入增加增益或降噪，应从实际播放和拾音布局处理。

### 3. 更换设备后失败

结束会话、重新选择音源并测试，不要依赖旧设备 ID 永久有效。蓝牙连接、USB 重插和默认设备变化都可能改变当前可用端点。

默认回环缺失不表示所有设备都不可用。若明确输出端点存在，先单独测试；若流打开失败，保留原生错误和设备信息反馈。

## 三、启动和运行组件 {#startup}

### 1. 试听正常，但开始同传失败

试听不加载模型。继续检查权重是否安装、模型配置是否完整、组件是否可用、设备后端是否匹配，以及语言是否受支持。

“设备检测未能完成”可能与引擎启动有关，不等同于没有音频设备。查看支持码和日志中的失败阶段，不凭一句泛化提示直接判断硬件损坏。

### 2. 远程识别为什么不需要安装 PyTorch

远程服务承担推理，本机只执行采集和请求处理。全部远程方案不需要为了清除可选组件的未安装状态而下载环境。本地翻译仍需它自己的组件，混合方案应按本地部分准备。

### 3. Windows 有显卡，软件却没有可用 GPU

硬件目录、驱动、推理后端和模型支持是不同条件。对照计算设备页的系统显卡与可用设备，核对所装 PyTorch／llama.cpp 包是否含目标后端。

可以先用 CPU 和小模型验证其他链路，再定位 GPU。不要根据 CUDA 版本号大小选择，也不要将其他软件目录里的 DLL 复制进来。

### 4. 提示内存或显存不足

结束会话后检查识别和翻译是否共卡、其他应用占用、模型规模和上下文。先减小权重或上下文，再尝试调整设备与卸载层数。

磁盘文件大小不是显存要求。降低一次设置后重新开始短会话，记录实际分配；不要把所有限制拉到最大。

### 5. 结束后模型仍占内存

应用可能保留最近配置的权重以复用；不可取消的原生任务也可能在停止回执后继续清理。仅有占用不证明泄漏。

需要切换或释放时走软件流程，等待资源空闲。不要删除正在加载的文件或立即并行启动第二场会话。

## 四、模型与下载 {#downloads}

### 1. 已安装的模型不能选择

先确认是识别还是翻译用途，再检查配置、引擎和语言方向。模型文件存在不代表适合当前任务，自定义能力声明也不能让权重获得新语言。

如果更换目标语言后模型可选，原因可能是能力约束，不应立即重新下载。

### 2. 下载从头开始或进度没有完全恢复

断点复用依赖固定文件身份和完整分块。不同 URL、大小、摘要或分块参数可能不能复用，正在下载但尚未完成的块也不等于已保存进度。

不要手动合并来源不同的缓存。重试同一推荐文件时保留 `.downloads`，成功后软件清理对应范围缓存。

### 3. 下载校验失败

保留模型名、来源、失败阶段及日志。检查网络、磁盘和重新下载结果，不关闭校验，不将损坏文件标为已安装。来源里同名的文件不一定与项目固定版本一致。

### 4. 镜像和代理为什么没有改善所有请求

PyPI、模型与 GitHub 组件下载分别配置。下载代理开关不等于所有远程推理请求的统一代理；先确认请求属于哪条路径，详见[环境配置](../getting-started/environment)。

## 五、原文与译文 {#translation}

### 1. 有原文，没有译文

按以下顺序检查：

1. 翻译服务是否启用，目标语言是否关闭。
2. 原文和目标语言是否受所选翻译模型支持。
3. 本地权重、模板和组件是否正常。
4. 远程 API 格式、基础地址、模型 ID 和凭据是否匹配。
5. 服务余额、额度、限流及实际错误是否正常。

阿里云连接译文只适用于阿里云识别；MiniMax 没有对应内置译文，需要另选翻译。

### 2. 检查密钥显示成功，为什么仍认证失败

“检查密钥”只验证本机保存的凭据能否读取，不向服务商发请求。它不会检查密钥是否已撤销、余额、地域、模型权限或 URL。

用短会话验证实际调用，区分本地保存和远程服务成功。不要反复复制同一密钥而不检查地域和接口。

### 3. 译文被截断或语言不对

核对目标语言、模型 ID、输出 Token 预算和服务返回。输出预算过小可能截断；把预算调大也不保证模型遵循指令，应检查模型是否适合翻译。

识别原文本身错误时，先纠正音源和原文语言，不能只调整翻译提示来掩盖输入问题。

### 4. 字幕在一句结束后才出现

MiniMax 先切段上传完整文件，译文也可能只在原文定稿后请求。MyMemory 为 REST 定稿翻译，不逐 Token 推送。

本地识别的分段、计算时间，远程排队和网络也会影响时机。持续本地语音按当前引擎的 6 秒上限拆分，这是应用等待预算，不是所有服务的上传限制。

### 5. 文字反复修改或看见重复句子

未定稿字幕修订是正常行为。同一片段会更新，不同片段可能包含真实重复发言，软件不按相同前后缀自动删除。

明显异常时记录发生时间、音源和是否跳转，提供最小可分享样例。不要只凭相同文字判断应在显示层合并。

## 六、远程接口错误

| 类型 | 意味着什么 | 处理 |
| --- | --- | --- |
| 认证／权限失败 | 凭据或资源归属不符合调用条件 | 核对账户、地域、空间、模型权限 |
| 余额不足 | 服务账户无法继续付费调用 | 到服务商检查账单与额度 |
| 限流 | 请求负载或配额窗口受限 | 降低并发和中间翻译，按要求等待 |
| 404／路径错误 | 地址层级或服务类型可能错误 | 核对基础地址与追加路径 |
| 模型不存在 | 标识错误或无对应权限 | 从服务端文档核对准确 ID |
| 网络超时 | 端点不可达或响应过慢 | 检查实际网络和服务状态 |

余额不足与限流需要不同处理。不要用频繁开始会话绕过错误，也不要为了排错把认证头和完整请求公开。

备用翻译可能使文字发送给第二个服务，并可能产生第二次费用。只设置了备用名称不代表备用连接已经有效。

## 七、浏览器字幕 {#browser}

### 1. 无法连接桌面

确认桌面运行、总连接许可、对应 Chrome／Edge 开关、Native Messaging 注册、扩展启用和桌面服务状态。浏览器管理页的扩展开关与 Nola 的连接许可不同。

### 2. 更新后提示版本不匹配

加载与桌面匹配的扩展目录，在浏览器管理页重新加载，再刷新旧视频页。后台新版本不会自动替换旧页面中运行的内容脚本。

### 3. 共享失败或没有声音

标签页模式必须由用户点击触发共享，选当前标签页并共享音频。取消、选错目标或没有音轨时重新授权。系统模式则检查桌面输出设备，不应等待标签页选择框。

静音提示可恢复，不一定表示授权失败。先播放语音，再判断是否有信号。

### 4. 只有某个网站不显示

其他 HTTPS 网站需要扩展弹窗授予站点权限。若权限正常，再检查嵌入播放器、CSP、跨域 iframe、封闭 Shadow DOM 和画中画等范围。记录具体网站和浏览器版本，不能承诺所有播放器都支持。

### 5. 在记录页找不到视频字幕

浏览器使用临时会话，不创建桌面记录和录音。需要保存的内容应事先选择桌面方案，不能在结束后补出未保存的历史。

## 八、记录与数据 {#records}

### 1. 更新或迁移后记录不见了

先查看实际数据目录和历史位置。新安装、旧安装沿用目录和用户自定义路径可能不同。停止写入并保留原目录，不立即恢复设置或创建同名文件覆盖。

### 2. 记录存在但不能播放

检查本场是否开启保存录音、对应文件是否仍在、磁盘是否可读。没有保存录音是合法状态，文字记录仍可能正常。

### 3. 换电脑后密钥失效

加密凭据依赖 Windows 用户环境，复制配置不能保证跨电脑解密。通过对应输入框重新保存，需要撤销旧密钥时在服务商处处理。

### 4. 恢复出厂设置能清空所有内容吗

不能。它恢复偏好，保留模型、记录和存储位置，不是凭据撤销和数据擦除工具。不同数据应按[隐私协议](../legal/privacy-policy)分别管理。

## 九、如何继续排查

重现一次后记录版本、音源、模型、语言、实际设备、错误码和发生阶段。打开本次启动日志，检查敏感内容后提交，不必公开完整数据目录。

若已尝试多个方案，按顺序说明每次只改了什么及结果。这比“全试过了”更有助于维护者判断。完整模板见[如何反馈](./feedback)。
