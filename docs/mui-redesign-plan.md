# Material UI 界面重做计划

## 当前状态

- 已安装 Material UI、MUI 图标与 Emotion，并配置项目级 MUI MCP。
- 本轮交互 Demo 已移除；现有 Electron 界面、Fluent 图标与引擎流程未替换。
- 正式开发前，以用户选定的首页参考图为视觉基线。首页使用左侧实时字幕大卡片、右侧历史记录和设置两张卡片，右上角切换语言。

## 设计基线

1. 统一定义浅色、深色主题和跟随系统模式，包括主色、背景、文字、边框、间距、圆角、字体与组件状态。字体优先使用 Windows 自带的 Segoe UI Variable 和 Microsoft YaHei UI。
2. 首页保留参考图中的卡片比例、说明、字幕预览、装饰和入口按钮。其他页面沿用同一设计变量。
3. 主功能只设实时字幕、历史记录、设置。设置下集中模型与服务、字幕外观、音频、翻译、存储、语言和诊断。
4. 最小窗口 760×560 下应可操作；验证全屏、Windows 缩放、键盘焦点和高对比度模式。

## 实施顺序

### 1. 设置与模型结构

- 模型使用两个独立维度：`类别 = 翻译模型 / 语音模型`，`模式 = 本地模型 / Ollama 兼容 / OpenAI 兼容`。
- 分开建模服务连接、模型条目和默认用途，允许同一模式下配置多个服务实例。
- 梳理 Microsoft Translator 等现有后端的兼容映射或专用适配方式。
- 设计旧设置与凭据迁移，确保已安装模型、云端配置和密钥不丢失。
- 云端 ASR 需补齐真实引擎适配与能力验证，再在界面标为可用。

### 2. 页面与真实流程

- 实时字幕工作页接入当前音频设备、识别与翻译选择、会话启停、实时字幕事件和浮层控制。
- 每次成功启动建立独立会话，记录开始、结束时间；每段字幕记录相对时间戳、原文和译文。历史列表支持搜索、详情、导出和确认删除，尊重用户的历史保存偏好。
- 设置页接入资源下载、安装状态、服务地址、凭据安全存储、连接测试、字幕外观与应用主题。
- 统一保存反馈、加载状态、错误处理和危险操作弹窗。

### 3. 迁移与验收

- 新页面接入真实功能并通过验收后，替换默认 UI；然后移除 Fluent 图标依赖和不再使用的旧 CSS、页面。
- 保留字幕浮层独立配色和 Electron 窗口行为。
- 验证中英文、浅色/深色/系统模式、760×560 到全屏、125%/150% 缩放、键盘操作和对比度。
- 运行类型检查、构建、单元测试和 Electron 布局测试；手动走通模型安装/删除、云端凭据、会话记录和导出、错误恢复。
