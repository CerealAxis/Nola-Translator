# FluentCaptions 界面与窗口基线

## 窗口尺寸

- 默认主窗口：`1180 × 780` CSS 像素；
- 最小主窗口：`760 × 560` CSS 像素；
- `resizable` 始终为 `true`，不设置最大尺寸；
- 主窗口在页面准备完成后显示，避免启动白屏；
- Windows 11 使用系统 Mica 背景，控件表面使用半透明层级。

## 响应式规则

- 大于等于 `1450px`：会话配置和字幕预览并排；
- `901px–1449px`：完整侧栏，主要内容纵向排列；
- 小于等于 `900px`：侧栏收起为图标导航；
- 小于等于 `700px`：表单、设置卡片和诊断卡片改为单列；
- 高度小于等于 `650px`：缩小页面纵向留白，内容区域允许滚动。

这些宽度以 CSS 像素计算，因此 Windows 125%、150% 或 200% DPI 下仍按可用逻辑空间重新排版。

## Fluent 视觉规则

- 字体使用 `Segoe UI Variable Text`，中文回退到 `Microsoft YaHei UI`；
- 控件圆角使用 6–7px，内容表面和字幕浮层使用 12px；
- 颜色优先使用 Windows 强调色语义，避免大面积高饱和色；
- 页面进入和状态变化使用 167ms 动效；
- 用户开启“减少动画”后，将非必要动画缩短到近乎无动画；
- 高对比度模式取消透明、阴影与模糊，改用系统颜色和明确边框。

## 标题栏与安全

- 使用 Electron Window Controls Overlay 保留系统最小化、最大化、关闭和 Snap Layout；
- 标题栏拖动区域不承载可点击控件；
- 渲染进程启用沙箱、上下文隔离并禁用 Node.js 集成；
- HTML 设置 Content Security Policy，不加载远程脚本。
