# Windows 音频管线

FluentCaptions 使用 PyAudioWPatch 访问 Windows WASAPI。系统输出通过 loopback 设备采集，麦克风列表只包含真实输入设备，不把 loopback 重复显示为麦克风。

## 设备标识

PortAudio 的数字 index 只在当前枚举周期内有效，不能持久化。引擎会根据设备类型、规范化友好名称、采样率和声道数生成应用内 ID；开始会话和设备恢复时重新枚举，再把应用内 ID 映射到当前 index。

- “默认系统输出”始终跟随 Windows 当前默认输出设备；
- 用户明确选择的设备消失后，只等待同一应用内 ID 恢复，不擅自切换到默认麦克风或其他设备；
- 设备检查默认每 2 秒一次；活动流停止时抛出明确的设备断开错误，供会话层发送状态事件。

## 采集与标准化

PortAudio callback 只复制输入字节并放入非阻塞队列。队列默认容纳 100 个 20 ms 块，即约 2 秒；满载时淘汰最旧块并累计 `dropped_chunks`，不会阻塞系统音频线程。

识别器只接收统一的 `AudioFrame`：

| 字段 | 固定值 |
|---|---:|
| 采样率 | 16,000 Hz |
| 声道 | 单声道 |
| 数据类型 | float32 |
| 每帧时长 | 20 ms |
| 每帧样本 | 320 |
| 数值范围 | -1.0 到 1.0 |

多声道先混合为单声道，44.1/48 kHz 等输入通过带有限历史重叠的 polyphase 重采样转换为 16 kHz。时间戳以单调时钟为基准，后续帧按样本数递增，不使用可能回拨的系统时间。

## 隐私

采集块和标准帧只驻留内存，不写入临时文件、历史记录或日志。诊断信息只记录设备友好名称、格式、丢块计数和队列状态，不记录音频内容。

当前锁定的 Python 3.13 x64 wheel 为 NumPy 2.5.1、SciPy 1.18.0 和 PyAudioWPatch 0.2.12.8，均由项目虚拟环境通过阿里云 PyPI 镜像安装。
